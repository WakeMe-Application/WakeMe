# 깨워줘 (WakeMe) — 브랜드

| 항목 | 값 |
|---|---|
| 앱 이름 (표시) | **깨워줘** |
| 영문·식별자 | **WakeMe** (레포·Xcode 타깃·Swift 패키지) |
| 번들 ID | `com.rosieoh.wakeme` · 위젯 `com.rosieoh.wakeme.widgets` |
| 한 줄 설명 | 지하철 하차 알림 |

## 이름을 바꾼 이유

이전 이름은 **이번역 / ThisStop**이었다. 버린 이유는 취향이 아니라 충돌이다.

- 앱스토어에 **이번정거장 — 실시간 지하철 위치, 정차, 하차 알림**이 이미 있다. 카테고리가 같고 이름이 한 글자 차이로 읽힌다.
- 그 앱의 도메인이 **thisstop.co.kr**이다. 영문 이름까지 정면으로 겹친다.

**깨워줘**는 경쟁 앱들이 전부 기능 서술형(이번정거장·여기어디역·하차요·지하철역 알람)이라 그 사이에서 눈에 띄고, 사용자가 앱에게 하는 말이라 제품이 하는 일과 정확히 일치한다. 나중에 버스·기차로 넓혀도 이름을 다시 바꿀 필요가 없다.

영문 `WakeMe`는 앱스토어 이름이 아니라 **내부 식별자**로만 쓴다(레포·타깃·번들 ID). 앱스토어에 노출되는 이름은 언제나 한글 **깨워줘**이므로, 알람시계 카테고리에 있는 동명 앱들과는 부딪히지 않는다.

## 마크

노선 위의 **역 노드(고리)**와, 거기서 **옆으로 빠져나가는 화살표**다. 열차는 계속 가고 사용자는 여기서 내린다 — 앱이 알려 주는 바로 그 순간을 그린 것이다.

아래로 향하는 화살표(다운로드 아이콘으로 읽힘)와 파동 표현(와이파이로 읽힘)은 시안 단계에서 버렸다. 옆으로 나가는 화살표만 60px 크기에서도 뜻이 남는다.

## 파일

```
brand/
  icon-1024.png    앱 아이콘 원본 (라이트)
  wordmark.png     아이콘 + 이름 + 한 줄 설명 (문서용)
App/WakeMe/Assets.xcassets/AppIcon.appiconset/
  AppIcon-light.png    기본. 브랜드 파랑 배경 + 흰 마크
  AppIcon-dark.png     다크. 배경 없이 마크만 (시스템이 배경을 깐다)
  AppIcon-tinted.png   틴티드. 회색조 (시스템이 휘도로 색을 입힌다)
```

## 다시 만들기

```bash
swift tools/build_logo.swift   # 저장소 루트에서
```

마크는 코드로 그린다(CoreGraphics). 색·굵기·비율을 바꾸려면 `tools/build_logo.swift` 위쪽의 기하 상수(`ringCX` `bar` `ringR` `tip` `arm`)만 고치면 세 가지 아이콘과 워드마크가 함께 갱신된다.
